# 🛫 SQL Mini Project: Flight Booking System

## ✈️ Story: What Keeps the Skies Running Smoothly?

Behind every booked ticket, every airport gate, and every flight status update lies a network of data points. This project dives into that data and tells the story of how flights, passengers, and bookings connect through SQL.

Imagine you are part of the data team at a growing airline. You’ve been asked to help understand booking trends, passenger activity, and flight performance. Using SQL JOINs and aggregation queries, you’ll uncover insights from the airline’s core database.

---

## 🗃️ Database Overview

This system includes 3 core tables:

- `passengers`: Stores personal details of flight passengers
- `flights`: Contains information about each scheduled flight
- `bookings`: Links passengers to flights with booking metadata

---

## 💡 Use Cases Solved in This Project

| File Name                          | Description                                               |
|-----------------------------------|-----------------------------------------------------------|
| `1_passenger_flight_list.sql`     | View all passengers with their corresponding flight details |
| `2_flight_occupancy_stats.sql`    | See how many passengers are booked on each flight         |
| `3_top_booked_routes.sql`         | Identify the top 3 most popular flight routes             |
| `4_bookings_per_passenger.sql`    | Know how frequently each passenger travels                |
| `5_flight_status_summary.sql`     | Track how many flights are scheduled, delayed, or cancelled |

---

## 🧠 SQL Concepts Used

- `JOIN` and `LEFT JOIN`
- Aggregations: `COUNT()`
- `GROUP BY`, `ORDER BY`, `LIMIT`
- Filtering with `WHERE`

## 🚀 How to Use

1. Import the `DataBase.sql` file into your SQL environment to create and populate the tables.
2. Run any of the `.sql` files in this folder to view specific insights.
3. Use this as a base for building dashboards or expanding your analysis.
